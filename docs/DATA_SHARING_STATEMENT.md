# Data Sharing Statement

## Manuscript-Ready Version

The Fitzpatrick17k and Stanford Diverse Dermatology Images (DDI) source datasets are publicly available through their respective repositories. Source images were not redistributed. The MD5-hash identifiers defining the 231-image Fitzpatrick17k cohort, identifiers defining the 252-image DDI cohort, data dictionary, adjudication dictionaries, per-image application outputs, derived analysis files, and R scripts are available at **https://github.com/jsonchen47/dermatology-ai-skin-tone-benchmark**. Access to and use of source images remain subject to the original dataset terms. No standalone software package was developed for this analysis. A version-specific Zenodo DOI will be added after release archiving.
