# Data Sharing Statement

## Manuscript-Ready Version

The Fitzpatrick17k and Stanford Diverse Dermatology Images (DDI) source datasets are publicly available through their respective repositories. Source images were not redistributed. The MD5-hash identifiers defining the 231-image Fitzpatrick17k cohort, identifiers defining the 252-image DDI cohort, data dictionary, adjudication dictionaries, per-image application outputs, derived analysis files, and R scripts are available at **https://github.com/jsonchen47/dermatology-ai-skin-tone-benchmark** and archived in Zenodo at **https://doi.org/10.5281/zenodo.21754439**. Access to and use of source images remain subject to the original dataset terms. No standalone software package was developed for this analysis.

## Before Submission

The Data Sharing Statement cites the version-specific DOI for release `v1.0.0`, not the all-versions concept DOI.
